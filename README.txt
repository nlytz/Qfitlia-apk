QFITLIA INTERACTIVE - ANDROID STUDIO PROJESI

Bu proje kullanicinin gonderdigi HTML ve img.zip dosyalariyla hazirlanmistir.
Internet gerektirmez. Tum HTML ve gorseller APK icine assets olarak paketlenir.

ANDROID STUDIO:
1. Android Studio > Open
2. Bu ZIP'i acip cikardiginiz QfitliaAndroid klasorunu secin.
3. Gradle Sync tamamlaninca:
   Build > Build App Bundle(s) / APK(s) > Build APK(s)
4. APK genellikle:
   app/build/outputs/apk/debug/app-debug.apk
   yolunda olusur.

OZELLIKLER:
- Tam ekran / immersive
- Landscape kilitli
- Browser/adres cubugu yok
- HTML JavaScript aktif
- Yerel img/ klasoru kullanilir
- Internet izni yok
- Android geri tusu uygulamayi kapatmaz
